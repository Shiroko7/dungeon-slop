# M1.2 review guide

This milestone keeps authored prose safe while generated proposals remain explicitly unapplied.

## Included

- AI config and blueprint results live as proposed values until Generate/Reroll/accept is completed.
- Any replacement of overview or room prose checkpoints the previous value in `authored_revisions`.
- Revision history can be listed and restored through `/api/dungeons/:id/revisions`; restore is a new mutation.
- Generation forks any existing map (including overview-only or geometry-only authored maps), and fork operation IDs make retries idempotent.
- Room narrator results carry stable `roomId` values. Unknown, duplicate, malformed, and missing results are reported without positional zipping; missing rooms can be retried.
- Room and overview editors retain unfinished drafts in browser storage.
- Chat Edit only submits a replacement transcript after the user confirms it; a failed request leaves the visible transcript untouched.
- Ctrl/Cmd+Z and Ctrl/Cmd+Y leave native text-field undo/redo to the browser.

## Verification

```text
bun x tsc --noEmit --allowJs false --skipLibCheck
bun run build
bun test
```

The automated suite covers revision checkpoints/restores and idempotent fork retries in `src/api/routes.test.ts`. Live browser verification remains a follow-up because the local browser automation bootstrap is unavailable in this environment.
